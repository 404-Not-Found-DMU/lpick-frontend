# 02-🐞-버그-이슈.md
## 📌 이슈 제목
> 위키 페이지 로딩 중 스켈레톤 렌더링 안되는 버그 수정

## ❗ 버그 설명
- 위키 뷰어 페이지에서 데이터 로딩 중 스켈레톤 컴포넌트가 나타나지 않는 문제가 발생합니다.

## 🔁 재현 방법
1. `/wiki/view/123` URL로 직접 접근
2. API 응답 지연 시에도 스켈레톤이 표시되지 않음

## ✅ 예상 동작
- 데이터 로딩 중에는 스켈레톤 UI가 정상적으로 표시되어야 합니다.
